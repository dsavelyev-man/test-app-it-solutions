# Тестовое задание для IT Solutions Management International Pte. Ltd.

Apollo Sandbox `/graphql`

Проект поделен на логические группы по основному своему функционалу.\
Использован dataloader для решения проблемы n+1 в запросах с связями вообще по хорошему обьединнять их в один запрос каким нибуть способом вместо такого также в dataloader была добавлена пагинация. для пагинации пришлось использовать $queryRawUnsafe так как Prisma.Sql не поддерживает такие комплексные работы с строками, но от пользователя идут лишь page и limit и то они проверяются на то числа они или нет. лучше использовать какую то библиотеку с защитой типа drizzle или knex
включенны логи prisma что бы было видно отсуствия этого.\
Компания убрана в отдельную таблицу так как логически в одной компании могут работать разные сотрудники и также принадлежать они одному проекту.\
Использована prisma 7 вместо только вышедшей в release candidate 8 которую разработчики везде суют версии так как она не надежна и плюс еще не успели библиотеки обновится которые зависят от нее и да поэтому prisma7.config.ts название файла..\
Использован как пару месяцев вышедший nest 12 поэтому везде у импортов расширение .js(наконец можно поставить adminjs без танцев с бубном).\
В `Dockerfile` сначала копируется только package*.json для эффективного использования кэша докер сборщика.\
Папка `common` имеет обобщенный характер так как проект небольшой.\
Prisma и Config установленны как глобальные так как не вижу причин ограничивать по импортам так как они используются практически везде.\
Выбрана postgres вместо sqlite для тестового так как не типы данных могли хранится в sqlite.

# Запуск приложения(docker)

Самый простой способ.
скопировать `.env.example` и назвать `.env`  
Дальше вызвать `docker compose up -d`

в образе была оставлен faker так как может вам захочется подробнее рассмотреть проект  
`docker compose exec api npx prisma db seed me fakeCompanies fakeProjects fakeApplicants randomConnect projectsToApplicants`\
позволяет заполнить бд фейковые данные с использованием faker\
она может выдавать иногда ошибки при выполнение но это не страшно оно выдает конфликты между связями

# Запуск приложения(bare)

нужен инстанс postgres  
скопировать `.env.example` и назвать `.env`  
указать в .env путь и секреты до postgres  
npm install  
`npx prisma migrate deploy`  
`npx prisma db seed me`  
или если нужны фейковые данные
`npx prisma db seed me fakeCompanies fakeProjects fakeApplicants randomConnect projectsToApplicants`  
`npm run start:dev`
и api будет доступно по порту указаному в .env
